# 📚 sc-gate-dl documentation

Read the pages in this order. The first two get you to your first download, and the rest are for when you need them.

| Page | Read it when |
| --- | --- |
| 1. 📦 [Installation](installation.md) | You set up sc-gate-dl: requirements, accounts, the `.env` file, and logging in. |
| 2. 🚀 [Usage](usage.md) | You download tracks with the CLI, the Web UI or the userscript. |
| 3. 🔧 [Configuration](configuration.md) | You change the output format or folder, add a proxy, or look up any `.env` variable or `config.json` key. |
| 4. 🧠 [How it works](how-it-works.md) | You want to know where sc-gate-dl looks for a gate, how it unlocks it, and how it converts and tags the file. |
| 5. 🏠 [Running on a server](server.md) | You run sc-gate-dl on another machine: network access, a remote headed browser with noVNC, and Tailscale. |
| 6. 🔌 [HTTP API](api.md) | You write a client for the API, such as [Nevumi](https://github.com/D3SOX/Nevumi). |
